1. 화면과 음성 처리

앱은 사용자가 Android 시스템의 화면 캡처를 승인하고 REC 버튼을 누르면 카운트다운 후 화면을 녹화합니다. 화면에 표시되는 개인 정보나 다른 앱의 콘텐츠도 녹화 영상에 포함될 수 있으므로 녹화 전에 확인해 주세요.

마이크 녹음을 선택하고 권한을 허용한 경우 주변 음성과 마이크 입력을 영상에 포함합니다. 무음 선택 시 마이크를 사용하지 않습니다. 현재 기기 내부 오디오는 캡처하지 않습니다.

화면 영상과 마이크 음성은 사용자의 기기 안에서 처리·저장되며 운영자 서버나 광고 서비스에 영상 파일로 전송하지 않습니다. 별도의 회원가입이나 계정 로그인을 요구하지 않습니다.

2. 권한의 사용 목적

  • 화면 캡처 승인: 사용자가 요청한 화면 녹화
  • 다른 앱 위에 표시: REC 버튼과 녹화 시간·일시정지·정지 버튼 표시
  • 마이크: 사용자가 선택한 마이크 음성 녹음
  • 포그라운드 서비스와 알림: 녹화 기능 유지 및 종료 안내
  • 인터넷과 네트워크 상태: 광고 제공과 동의 관리

녹화 기능은 사용자의 조작으로 시작하고 종료됩니다. Android 설정에서 해당 권한을 변경할 수 있으며, 권한을 취소하면 관련 기능을 사용할 수 없거나 녹화가 중단될 수 있습니다.

3. 보관과 삭제

완료된 녹화 영상은 앱 내부 저장소에 임시 보관하여 미리보기로 제공합니다. 삭제를 확인하면 해당 내부 영상을 삭제합니다. 갤러리 저장을 선택하면 MP4 영상을 Movies/AtticSoft에 복사하고 앱 내부의 해당 임시 파일을 삭제합니다.

앱 내부 영상과 상태 정보는 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하여 삭제할 수 있습니다. 갤러리에 저장한 영상은 앱을 제거해도 남을 수 있으며, 갤러리에서 직접 삭제해야 합니다.

4. 광고와 외부 서비스

앱 하단 배너에는 Google AdMob(Google Mobile Ads SDK)을 사용하고, 필요한 지역의 광고 동의에는 Google User Messaging Platform(UMP)을 사용합니다.

Google 광고 SDK는 광고 제공·측정 및 부정 이용 방지를 위해 IP 주소, 앱 사용·상호작용 정보, 성능 및 진단 정보, Android 광고 ID와 앱 세트 ID 등 기기·계정 식별자를 수집·공유할 수 있습니다. IP 주소는 대략적인 위치 추정에 사용될 수 있습니다. 실제 처리 범위는 기기 설정, 지역, 동의 선택과 서비스 구성에 따라 달라집니다. 광고 SDK가 전송하는 데이터와 녹화 영상의 기기 내 처리는 별개입니다.

Google이 처리하는 데이터의 보관과 권리 행사에는 해당 서비스의 정책이 적용됩니다.

  • Google 개인정보처리방침
  • Google 광고 및 데이터 사용 안내
  • Google Mobile Ads SDK 데이터 공개 안내

5. 동의와 사용자 선택

필요한 지역에서는 광고 동의 화면을 제공합니다. 앱 하단 광고 영역을 길게 누르면, 해당 지역에서 필요한 경우 광고 개인정보 설정을 열 수 있습니다. Android 설정의 광고 개인정보 메뉴에서도 지원되는 선택을 변경할 수 있습니다.

6. 문의 정보와 개인정보 보호

이메일 문의 시 운영자는 회신과 문제 해결을 위해 발신 이메일 주소와 문의 내용을 처리합니다. 녹화 영상을 문의에 첨부할 필요는 없습니다. 문의 자료는 대응 목적에 필요한 기간 동안 보관하고, 삭제 요청은 아래 이메일로 접수합니다. 법령상 보관 의무가 있는 경우에는 해당 기간을 따릅니다.

운영자는 문의 정보에 대한 접근을 필요한 범위로 제한합니다. 앱의 기능이나 데이터 처리 방식이 바뀌면 이 페이지와 시행일을 갱신하고 필요한 경우 앱에서도 안내합니다.
