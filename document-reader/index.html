다락 문서뷰어

내 손안의 문서 서재 · 보기 전용 Android 앱

문서 읽기에 집중하세요

PDF, 한글(HWP/HWPX), 워드(DOC/DOCX), 엑셀(XLS/XLSX), 프레젠테이션(PPT/PPTX)을 하나의 앱에서 열어보세요. 문서는 기기 안에서 처리하며 로그인이나 인터넷 연결이 필요하지 않습니다. 원본을 편집하거나 덮어쓰지 않습니다.

1.0.3 테스트 버전 · 18.8 MB · Android 9 이상

APK 다운로드

게시일: 2026년 10월 13일

읽는 방법

  • 앱에서 ‘문서 열기’를 누르거나 다른 앱의 연결 앱 목록에서 ‘다락 문서뷰어’를 선택하세요.
  • 문서는 처음부터 화면의 너비와 높이에 맞춰 표시됩니다. 휴대폰을 회전하면 페이지 전체를 다시 맞춥니다.
  • 문서를 탭하면 도구막대가 숨겨져 읽기에 집중할 수 있습니다. 다시 탭하거나 작은 ‘⋯’ 버튼을 누르면 돌아옵니다.
  • 집중 보기의 화면 맞춤 상태에서 왼쪽으로 밀면 다음 페이지, 오른쪽으로 밀면 이전 페이지로 이동합니다. 엑셀에서는 시트가 바뀝니다.
  • 두 손가락으로 확대할 수 있습니다. 확대 중에는 드래그하여 문서 안을 이동합니다.

설치 방법

  1. Android 휴대폰에서 위 APK를 다운로드하고 엽니다.
  2. 설치가 차단되면 Android 안내에 따라 다운로드에 사용한 브라우저 또는 파일 앱의 ‘이 출처 허용’을 켜고 설치하세요.
  3. 이전 테스트 버전을 사용 중이라면 기존 앱 위에 업데이트 설치할 수 있습니다.

파일을 열 때 연결 앱에서 ‘다락 문서뷰어’를 선택하고 ‘항상’을 누르면 해당 형식의 기본 앱으로 사용할 수 있습니다.

1.0.3에서 달라진 점

  • 페이지가 크게 보였다가 축소되던 현상 개선
  • 가로 화면에서 페이지가 잘리지 않도록 전체 맞춤 적용
  • 문서 탭으로 집중 보기 전환 및 좌우 페이지 넘김 추가

지원 범위

문서당 최대 64 MB이며 편집 기능은 없습니다. 기기에 없는 글꼴은 대체 글꼴로 표시됩니다. 복잡한 표·도형·차트·수식과 페이지 나눔은 원본 프로그램과 다를 수 있고, 동영상과 애니메이션은 재생하지 않습니다. 구형 DOC/XLS/PPT는 일부 요소가 생략될 수 있습니다.

현재 테스트 APK입니다. 브라우저 자동 검사와 Android 빌드 검사를 통과했으며, 실제 기기별 동작은 다를 수 있습니다.
