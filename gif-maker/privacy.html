1. 영상과 GIF 처리

광고 없는 GIF 메이커는 사용자가 선택한 동영상을 Android 기기에서 GIF로 변환합니다. 앱은 영상과 GIF를 운영자 서버에 업로드하지 않습니다. 별도의 회원가입이나 계정 로그인을 요구하지 않습니다.

선택한 파일의 접근 정보, 변환 구간, 해상도와 프레임 설정은 기기에 저장됩니다. 앱 내부의 변환 결과는 다음 변환이 완료되면 교체됩니다. 사용자가 지정한 위치에 저장한 GIF는 사용자가 직접 관리합니다.

2. 광고와 외부 서비스

앱은 Google AdMob(Google Mobile Ads SDK)으로 광고를 제공하고 Google User Messaging Platform(UMP)으로 필요한 광고 동의를 관리합니다.

Google 광고 SDK는 광고 제공·측정, 서비스 개선, 보안 및 부정 이용 방지 등을 위해 IP 주소, Android 광고 ID와 앱 세트 ID 등 식별자, 앱 상호작용 정보, 진단 정보를 수집하거나 공유할 수 있습니다. IP 주소는 대략적인 위치 추정에 사용될 수 있습니다. 처리 범위는 SDK, 기기 설정, 지역 및 사용자의 동의 선택에 따라 달라집니다.

운영자가 영상 파일을 전송하지 않는 것과 별개로, 광고 SDK의 데이터는 Google에 전송될 수 있습니다. Google의 데이터 보관 및 처리에는 해당 서비스의 정책이 적용됩니다.

  • Google 개인정보처리방침
  • Google 광고 및 데이터 사용 안내
  • Google Mobile Ads SDK 데이터 공개 안내

3. 동의와 사용자 선택

필요한 지역에서는 광고 동의 화면을 제공합니다. 동의 변경이 필요한 경우 앱의 ‘개인정보처리방침’ 안내창에서 광고 개인정보 설정을 열 수 있습니다. Android 기기의 광고 개인정보 설정에서도 지원되는 선택을 변경할 수 있습니다.

4. 보관과 삭제

앱의 내부 설정과 변환 결과는 Android 설정에서 앱 데이터를 삭제하거나 앱을 제거하여 삭제할 수 있습니다. 별도로 저장한 GIF 및 원본 영상은 저장 위치에서 직접 삭제해야 합니다.

이메일 문의 시 운영자는 회신과 문제 해결을 위해 이메일 주소와 문의 내용을 처리합니다. 문의 자료는 대응 목적에 필요한 기간 동안 보관하며, 삭제 요청은 아래 이메일로 접수할 수 있습니다. 법령상 보관 의무가 있으면 해당 기간을 따릅니다. 광고 서비스가 수집한 데이터의 처리 및 권리 행사 방법은 Google 정책을 참고하세요.

5. 개인정보 보호와 변경

운영자는 문의 등으로 제공받은 개인정보를 필요한 범위에서 처리하고 접근을 제한합니다. 앱의 기능이나 데이터 처리 방식이 달라지면 이 페이지의 방침과 시행일을 갱신하며 필요한 경우 앱에서도 안내합니다.
